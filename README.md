# Siege of Champions for Omarchy

An Omarchy theme inspired by the Moonforge visual style of Siege of Champions: moonlit blues, dark night, gold, and arcane light. Includes seven wallpapers from the game world.

## Install

```bash
omarchy theme install https://github.com/MayberryDT/omarchy-siege-of-champions-theme.git
```

Omarchy applies the theme after installation. Change wallpapers with `omarchy theme bg next`, or choose one from the background switcher.
